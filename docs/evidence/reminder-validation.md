# Reminder policy validation

> この文書はPDDR Kitの説明用に作成した架空の検証結果です。実在する製品テストではありません。

検証対象：[`example/reminder-policy.json`](../../example/reminder-policy.json)

| シナリオ | 期待結果 | 結果 |
|---|---|---|
| タイムゾーンを確認でき、ユーザー設定がない | ローカル時刻09:00を使用 | Pass |
| ユーザーが時刻を変更した | ユーザー設定を優先 | Pass |
| ユーザーが通知を無効化した | 通知を予約しない | Pass |
| タイムゾーンを確認できない | 時刻を推測せず設定を求める | Pass |

上記の範囲で、PDDR-0001に記録した判断が設定へ反映されていることを確認した。実際の通知配送、OS権限、夏時間移行はこの架空サンプルの検証対象外である。
