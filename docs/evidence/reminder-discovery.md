# Reminder discovery notes

> この文書はPDDR Kitの説明用に作成した架空のEvidenceです。実在する調査結果ではありません。

## 観測

- 「朝の水やり通知」は利用者自身の地域における朝として受け取られた。
- 09:00 UTC固定では、対象地域によって夜間または夕方の通知になった。
- 初回起動で通知時刻の入力を必須にすると、植物登録までの操作が一つ増えた。

## 制約

- v0.1では端末からタイムゾーンを確認できる前提とする。
- タイムゾーンを確認できない場合の時刻を推測しない。
- ユーザーが既定時刻を変更または通知を無効化できる状態を維持する。
